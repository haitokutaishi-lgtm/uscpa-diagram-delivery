# asset-group-relative-sales-value（ASC 360 / ASC 805-50）

- 公開URL：https://haitokutaishi-lgtm.github.io/diagram-site/topics/asset-group-relative-sales-value/
- FARテキスト：FAR1-3 5-1「取得原価の構成要素」（原価算入項目・算入しない項目・土地の設例）、5-2「資産グループの購入」（A/B/C を $120,000 で一括購入）

## 確かめた基準・出典
- 資産グループの取得は相対的な時価で配分、のれんは計上しない（ASC 805-50-30-3）
- 資産の取得の取引費用は原価に含める。企業結合の取得関連費用は費用（ASC 805-10-25-23）
- 新築目的の古い建物の撤去費は土地（廃材収入は控除）

## 決めたこと
- 「全体にかかる費用は総額に入れて配る／1つの資産だけの費用は直接足す」を論点2として独立させた
- slug は relative-sales-value だが、按分の基準は時価（fair value）と書く（slug は URL 維持のため変更しない）
