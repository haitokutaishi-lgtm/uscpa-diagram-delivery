## 確かめた基準・出典
- 重要な影響力は20%以上で推定、反証可能（ASC 323-10-15）
- fair value option は持分法の対象にも選べる・取消不能（ASC 825-10）。旧ページの「時価評価にはしない」の言い切りを修正した
- 内部利益は持分%分だけ消去（downstream / upstream とも）（ASC 323-10-35-7）
- 損失で投資勘定ゼロ → 停止。保証・追加支援の約束があれば続ける。再開は未計上損失を埋めてから（ASC 323-10-35-19〜22）
- 持分法への切替は将来に向かって適用（ASU 2016-07）
- 累積型優先株：宣言の有無にかかわらず優先配当を引いてから持分%（ASC 323-10-35-16）
