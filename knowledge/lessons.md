# 教訓・方針（テーマ横断）

新しい順に追記する。1項目＝何があったか＋どうするか。

## 2026-10-07 FAR は全範囲のロードマップで出す。AUD は火・金で別枠

- **何があったか**：キューが同じ10本ほどの「見直し」再配信を繰り返していた（旧型のまま）。ユーザー指示で、FAR は全範囲から重要論点を選び直し、AUD も FAR と重ならない曜日で配信する。
- **どうするか**：配信順は `knowledge/roadmap-far.md`（44本）と `knowledge/roadmap-aud.md`（34本）。キューは v2 の spec ができたテーマまでしか補充しない（`require_v2`）ので、配信を止めないには**少なくとも6本先まで v2 を作っておく**。AUD は `delivery-config.json` の `subjects.AUD.enabled` で開始。
- AUD の型：全体図は `matrix`（判定表）と `flow`、TBS は選択式。

## 2026-10-07 投稿文に所要時間を書かない

- **どうするか**：「約5分」は受講生にとって意味がない、とユーザー指摘。`post.minutes` は廃止。

## 2026-10-07 テキストの章番号は書かない

- **どうするか**：図解ページ（リード・本文）にも Discord 投稿文にも「テキスト4-7」のような章番号を書かない（受講生には関係ない、とユーザー指摘）。spec の `text_ref` は使わない。OCR は内容・用語を合わせるためだけに使う。

## 2026-10-02 Discord の投稿文を「開く理由がある」形にした

- **何があったか**：旧投稿は「【図解配信】タイトル＋いいね👍でリアクションください」だけで、開く理由も反応の取り方もなかった。
- **どうするか**：①論点名、②差がつく論点からの問い（答えは書かず、ページのどこにあるかだけ）、③できること3つ、④リアクション3択（✅ 全問正解／🤔 間違えた問題があった／📌 あとで解く）。spec の `post` に書く。
- **測り方**：リアクションの数をテーマごとのノートの「受講生の反応」に記録する。3択は固定し、テーマ間で比べられるようにする。

## 2026-10-02 旧型（10部構成・対話形式）をやめて復習シート型（v2）にした

- **何があったか**：コミュニティに定期配信していたが受講生の反応がなかった（閲覧数は計測していない）。見直すと、①「図解」なのに図がない文章の壁、②同じ例題を5回繰り返し、確認問題も答えを先に見せた同じ問題、③テキストの基本の焼き直しで差がつく論点がない、④毎回同じ10部テンプレ、が原因だった。
- **どうするか**：冒頭に全体図1枚、例題は1セット、差がつく論点は「ルール → 数字 → こう間違える」、引っかけは問題文の英語で一覧、確認問題は初見の数字（英語MC＋和訳トグル＋TBS入力式）。対話キャラは外した。基準は `.cursor/skills/uscpa-far-diagram-quality/SKILL.md`。

## 2026-10-02 試験範囲は全部載せる（VIP 論点解説と重なってもよい）

- **どうするか**：テキストで「発展」扱いの論点（例：持分法の basis difference）も入れる。VIP 向けとの差は動画解説と個別指導でつける（ユーザー判断）。

## 2026-10-02 FARテキストに合わせる

- **どうするか**：`07_ナレッジ/ナレッジ/予備校の教材/OCR済みMarkdown/`（ローカル）に該当章があれば、用語・論点の範囲をそろえる。転載はしない（文章・数字・問題はオリジナル）。
- 手元にあるのは FAR1-3（Ch1〜6）と FAR4（基礎 Ch1〜9）のみ。Investments（Unit 13）など未収録の章は、録画→OCR してから合わせ直す。
